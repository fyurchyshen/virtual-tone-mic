## Communication

See [CONTRIBUTING.md → Where things go](../CONTRIBUTING.md#where-things-go).

- **Response time:** try to reply to review requests and @mentions within one working day.
- **Blocked?** Say it early, in the issue and in chat. Being blocked silently costs the most time.

## Meetings

- **Weekly sync (~20 min):** what's done, what's next, what's blocking. Notes go in
  **Discussions → Meeting notes** using the template.
- **Ad-hoc calls** for design questions; the outcome goes into the related Decisions discussion.

## Status updates

When someone asks for progress, post it in **Discussions → Status updates** (template provided),
then share the link. Each update covers: done, next, problems and how they were solved.
