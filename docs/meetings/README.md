# Meetings

Meeting notes live in **Discussions → Meeting notes** so everyone gets notified and can comment.
The discussion form already contains the template below; use it if you write notes offline first.

## Template

```
# Meeting YYYY-MM-DD: <topic>

**Attendees:**

## Agenda
1.

## Notes and decisions
-

## Action items
- [ ] @name — action (#issue)
```

Every action item bigger than a few minutes gets an issue.
